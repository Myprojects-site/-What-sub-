# WhatSub 한글 패치

- **만든이:** 랑데부
- **버전:** 1.0 (2026-11-15)
- **기준 게임 버전:** WhatSub (Unreal Engine 5.8.4, 2026-11-11 빌드)

WhatSub를 한국어로 플레이할 수 있게 해 주는 비공식 한글 패치입니다.

---

## 설치 방법

### 자동 설치 (추천)

1. **게임을 완전히 종료**합니다.
2. 받은 압축 파일을 아무 곳에나 풉니다.
3. `WhatSub_한글패치` 폴더 안의 **`설치.bat`** 을 더블클릭합니다.
4. 창에 아래처럼 나오면 설치가 끝난 거예요. 아무 키나 눌러 창을 닫습니다.

   ```
   [1/3] 한글 패치 파일 복사 완료
   [2/3] 로딩 문구 한글화 완료
   [3/3] 게임 언어를 한국어로 설정 완료
   설치가 끝났어요! 게임을 실행하세요.
   ```

5. 스팀에서 게임을 실행합니다.

> 설치 프로그램이 스팀 라이브러리에서 게임 폴더를 자동으로 찾아요.
> 찾지 못하면 게임 폴더 경로를 물어보니 직접 입력해 주세요.
> (스팀 → WhatSub 우클릭 → 관리 → 로컬 파일 보기 에서 경로를 확인할 수 있어요.)

> Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르세요.

### 수동 설치

자동 설치가 안 될 때만 이 방법을 쓰세요.

1. 게임을 종료합니다.
2. `Paks` 폴더 안의 파일 3개를 게임 폴더의 `Sub\Content\Paks\` 에 복사합니다.
   - `Sub-Korean_v4_P.pak`
   - `Sub-Korean_v4_P.utoc`
   - `Sub-Korean_v4_P.ucas`

   > ⚠️ 세 파일은 **반드시 함께** 있어야 합니다. 하나라도 빠지면 패치가 적용되지 않아요.

3. 게임 언어를 한국어로 바꿉니다. 둘 중 하나만 하면 돼요.
   - 스팀 → WhatSub 우클릭 → 속성 → 일반 → **실행 옵션**에 `-culture=ko` 입력
   - 또는 `%LOCALAPPDATA%\Sub\Saved\Config\Windows\GameUserSettings.ini` 파일에 아래 두 줄 추가

     ```ini
     [Internationalization]
     Culture=ko
     ```

> 수동 설치에서는 로딩 화면의 "Generating world" 문구는 영어로 남아요.
> (이 문구는 게임 실행 파일 안에 있어서 자동 설치만 바꿀 수 있어요.)

---

## 제거 방법

1. 게임을 종료합니다.
2. **`제거.bat`** 을 더블클릭합니다.
   - 한글 패치 파일 삭제, 실행 파일 원본 복구, 언어 설정 제거를 자동으로 합니다.

수동으로 지우려면 `Sub\Content\Paks\` 의 `Sub-Korean_v4_P.*` 파일 3개를 지우고,
스팀에서 **게임 파일 무결성 검사**를 하면 됩니다.

## 알아 두세요

- **게임이 업데이트되면** 일부 문장이 영어로 나오거나 로딩 문구가 원래대로 돌아갈 수 있어요.
  `설치.bat` 을 다시 실행하면 로딩 문구는 다시 적용돼요.
  새로 추가된 문장은 패치가 업데이트되어야 번역됩니다.
- 스팀 **게임 파일 무결성 검사**를 하면 로딩 문구가 영어로 돌아가요. `설치.bat` 을 다시 실행하세요.
- 설치하면 **상호작용 키(E 등)를 직접 바꿔 둔 설정이 기본값으로 돌아갈 수 있어요.**
  설정 → 마우스 & 키보드 에서 다시 지정해 주세요.
- 꾸미기 아이템의 일부 안내 문구(`Requires achievement '...' to use.` 등)는 게임 구조상
  한글을 표시할 수 없어서 영어로 남겨 두었어요. (따옴표 안 업적 이름은 한국어로 나와요.)
- 키보드 키 이름(LMB, Space 등)과 개발자용 임시 문구는 번역하지 않았어요.
- 멀티플레이: 한글 패치는 내 화면의 글자만 바꿉니다. 친구가 패치를 설치하지 않아도 함께 플레이할 수 있어요.
- 이 패치는 비공식 팬 패치이며, 개발사와 관계가 없습니다. 사용으로 생기는 문제는 사용자 책임입니다.
